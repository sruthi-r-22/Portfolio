# Rentala Sruthi — Portfolio

A minimalist, high-contrast, editorial single-page web portfolio showcasing projects in AI/ML, Real-Time Voice Agents, Geospatial Analytics, and Full-Stack Systems.

---

## 🛠️ Tech Stack & Architecture

- **Frontend:** HTML5, CSS3 / Custom Styling, Tailwind CSS (Utility System), JavaScript (ES6+)
- **Design System:** Off-white/sand palette (`#EAE6DF`), deep charcoal contrast (`#161616`), editorial typography (Syne, Playfair Display, Plus Jakarta Sans)
- **Deployment:** GitHub Pages / Static Hosting

---

## 🚀 Key Projects Featured

1. **Farm Memory** — AI Voice Assistant for Indian Farmers  
   *Multi-agent conversational voice pipeline with episodic memory, dynamic function calling, and localized guardrails.*  

2. **SmartBundle AI** — Intelligent Retail & Cross-Selling Engine  
   *High-performance dynamic storefront delivering sub-50ms product bundle recommendations based on live cart state.*  

3. **BugTrace** — Android Telemetry & Automated Bug Detection  
   *Engineered end-to-end device telemetry capture over local Wi-Fi with real-time multi-signal crash analysis.*  

4. **Industrial Intelligence** — AI Document Q&A System  
   *Interactive Q&A pipeline over unstructured PDF manuals using context-grounded prompt engineering via Google Gemini API.*  

5. **PyroSentinel GIS** — Geospatial Fire Monitoring Prototype  
   *Pipeline distinguishing industrial heat anomalies from critical forest fire events using satellite thermal hotspots.*  


6. **PriceDrop** — Full-Stack E-Commerce Engine  
   *Interval price decay algorithms with server-enforced anti-manipulation checks and live inventory tracking.*
